# free-stack — organelle mapping decisions (Tier C, declared)

Docs-only repo: the free-stack master plan (100% free 24/7 company stack
design). No executable capabilities exist to decompose.

## Decision

- **Tier C declared.** One manifest (`free-stack.manifest.json`, 5 contracts
  covering the stack layers) with honest Candidate valence. No live host
  registration — there is nothing to execute.
- **Reference check:** the contracts describe *plan layers* (free AI APIs →
  Cloudflare → n8n → GH Actions → creative/ops services), not computations.
  None of the 12 reference organelles applies.
- **Deliberate non-decomposition:** splitting plan prose into fake "units"
  would be exactly the blind templating the doctrine forbids. One honest
  declared manifest is the correct shape.
